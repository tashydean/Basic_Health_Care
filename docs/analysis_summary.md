# Analysis Summary
노트북 실행 없이 분석 전체 흐름과 결론을 파악할 수 있는 요약 문서.

---

## 1. 배경 — 분석 방향 설계 과정

초기에 두 가지 방향을 검토했으나 데이터 구조적 한계로 모두 중단됨.

**시도 1. 진단 코드 기반 분류**<br>
PrimaryDiagnosisCode Long-tail 분포 → 희귀 진단이 다수로 분류 모델 구축 불가.

**시도 2. 재입원 패턴 분석**<br>
동일 환자 반복 입원이 임상 맥락 없이 독립 이벤트로 처리 → 인과 추적 불가.

위 과정을 거쳐 데이터에서 가장 정보 밀도가 높은 **검사 결과(111,483건)** 에 집중.<br>
"검사 수치의 이상 패턴이 입원 기간(LOS)과 어떤 관계인가"를 분석 대상으로 설정.

**핵심 가설**: 단순 평균보다 이상 소견 누적·변동성·시간적 추이가 LOS와 더 강한 연관성을 가질 것.

**데이터**: Synthea 합성 EMR — 100명 / 372건 입원 / 111,483건 검사

---

## 2. 피처 설계 — 4가지 관점으로 143개 변수 구성

검사명(LabName) 35종별로 4가지 관점의 피처를 생성, Wide Format으로 변환.

| 피처 그룹 | 설계 의도 | 피처 수 |
|-----------|-----------|---------|
| `Lab_Mean_{검사명}` | 기준 비교용 단순 평균 | 35 |
| `Lab_Std_{검사명}` | 개별 검사 변동성 | 35 |
| `Lab_Trend_{검사명}` | 수치 악화/호전 방향 (선형회귀 기울기) | 35 |
| `Abnormal_Sum_{검사명}` | 검사 단위 이상 소견 누적 | 35 |
| **`Total_Abnormal_Count`** | **환자 전체 중증도 → SHAP 1위** | 1 |
| `Total_Lab_Variability` | 환자 단위 전반 변동성 | 1 |
| `LabTestVariety` | 검사 종류 다양성 | 1 |

**`LabTestCount` 제외**: LOS와 r=0.993으로 역인과 관계 의심.<br>
제거 후에도 R²=0.918 달성 → 순수 임상 신호만으로 예측 가능 확인.

**데이터 구조 주의사항**: AdmissionID는 환자별 입원 순번(1, 2, 3...).<br>
모든 병합은 `['PatientID', 'AdmissionID']` 복합키로 수행 (단독 조인 시 행 폭발 발생).

## 3. EDA — 탐색 결과가 피처 설계 근거로 활용됨

| 분석 | 결과 | 해석 |
|------|------|------|
| 인구통계 | 성비 균형(F 52%), 60대 이상 밀집 | 다인종 합성 데이터 특성 |
| LOS 분포 | 평균 10.6일, 중앙값 10일 / 우측 편포 | 성별·연령별 LOS 차이 없음 |
| LabTestCount ↔ LOS | r = 0.993 | 역인과 위험 → 피처 제외 근거 |
| **PCA** | **PC1 설명력 7.0%** | **지배적 구조 없음 — 단순 평균으로 환자 구분 불가** |
| **t-SNE** | **균일 분포, 군집 없음** | **평균 수치 기반 환자 분리 불가** |
| **K-Means** | **K=2에서만 미약한 분리** | **임상적으로 의미 있는 자연 군집 없음** |

PCA / t-SNE / K-Means 결과 모두 "평균 기반 표현의 한계"를 실증.<br>
구조적 파생변수 필요성의 정량적 근거로 활용됨.

## 4. 모델링 결과

| 모델 | R² (Test) | MAE | CV R² (5-Fold) |
|------|-----------|-----|----------------|
| Linear Regression | 0.825 | 1.697일 | 0.712 ± 0.068 |
| Random Forest (Tuned) | 0.916 | 1.157일 | **0.890 ± 0.035** |
| **XGBoost** | **0.918** | **1.123일** | 0.872 ± 0.030 |

XGBoost Test R² 기준 최우수.<br>
CV R²는 RF가 근소하게 높아 소규모 데이터 특성상 두 모델은 실질적으로 동등하다고 해석.<br>
LR 대비 트리 계열 R² 격차 +0.09 → **비선형 구조 존재 확인**.

## 5. SHAP — 가설 검증

모델을 예측 도구가 아닌 **임상 신호 발굴 도구**로 활용.

| 피처 그룹 | SHAP 기여도 | 결과 |
|-----------|------------|------|
| **이상 소견 누적** | **70.1%** | `Total_Abnormal_Count` 단독 압도 (2위의 31배) |
| 변동성 | 중간 | 검사 수치 불안정성 반영 |
| **검사 평균** | **10.1%** | **하위 — 단순 평균의 한계 실증** |
| 시간 추이 | 하위 | 수치 악화/호전 방향 |

`Total_Abnormal_Count`의 SHAP Dependence Plot에서<br>
일정 수준 이상 시 효과가 급증하는 **임계점 패턴** 관찰 → 비선형 구조 시사.

**가설 검증 결과**

| 가설 | 결과 |
|------|------|
| 단순 평균은 충분하지 않다 | Lab_Mean 그룹 기여도 최하위(10.1%) — 확인 |
| 이상 누적이 핵심 신호 | Total_Abnormal_Count 70.1% 독점 — 확인 |
| 변동성이 불안정성을 반영한다 | Std/Variability 그룹 중간 이상 기여 — 확인 |
| 시간 추이가 방향 정보를 제공한다 | Trend 그룹 의미 있는 기여 — 확인 |

## 1. 분석 배경 및 목적

본 프로젝트는 EMR(Electronic Medical Record) 정형 데이터에 대한 **탐색적 데이터 분석(EDA)** 을 주목적으로 수행하였다.

원본 데이터(100명 / 372건 입원 / 111,483건 검사)를 탐색한 결과, 단순 평균값 기반 표현이 환자 상태의 이질성을 충분히 포착하지 못한다는 구조적 한계가 관찰되었다. 이에 더 깊은 탐색을 위해 **입원 기간(LOS)을 분석 대상**으로 설정하고, 검사 수치의 변동성·시간적 추이·이상 소견 누적 등 구조적 파생변수가 LOS와 어떤 관계를 갖는지 탐색하였다.

모델링은 탐색의 도구로 활용하였으며, EDA에서 세운 가설을 SHAP으로 실증하는 것이 분석의 핵심이다.

**분석 방향 전환 배경:**
- 진단 코드(PrimaryDiagnosisCode)는 Long-tail 분포로 분류 모델 구축 불가
- 재입원 기록이 임상 맥락 없이 독립 이벤트로 처리되어 인과 추적 불가
- → **검사 데이터 기반 생리적 불안정성 ↔ LOS 관계 분석**으로 초점 전환

**핵심 가설:** 검사 수치의 단순 평균보다 이상 소견 누적·변동성·시간적 추이가 LOS와 더 강한 연관성을 가질 것이다.

**데이터:** Synthea 합성 EMR 데이터 (100명 / 372건 입원 / 111,483건 검사)

## 2. Feature Engineering

실제 데이터에서는 검사명(LabName) 35종별로 피처가 생성되어 총 **143개 모델 피처**가 구성된다.

| 변수 그룹 | 예시 | 설계 의도 | 피처 수 |
|-----------|------|-----------|---------|
| `Lab_Mean_{검사명}` | `Lab_Mean_CBC: HEMOGLOBIN` | 기준 비교용 (단순 평균) | 35 |
| `Lab_Std_{검사명}` | `Lab_Std_CBC: HEMOGLOBIN` | 개별 검사 변동성 | 35 |
| `Lab_Trend_{검사명}` | `Lab_Trend_CBC: HEMOGLOBIN` | 수치 악화/호전 방향 (선형회귀 기울기) | 35 |
| `Abnormal_Sum_{검사명}` | `Abnormal_Sum_CBC: HEMOGLOBIN` | 검사 단위 이상 소견 누적 | 35 |
| **`Total_Abnormal_Count`** | — | **환자 전반적 중증도 → SHAP 1위 (70.1%)** | 1 |
| `Total_Lab_Variability` | — | 환자 단위 전반 변동성 | 1 |
| `LabTestVariety` | — | 검사 종류 다양성 | 1 |

`LabTestCount`(총 검사 횟수)는 LOS와 r=0.993이나 역인과 관계 의심으로 **제외**.
제거 후에도 XGBoost R²=0.918 달성 → 순수 임상 신호만으로 예측 가능함을 확인.

## 3. EDA 주요 결과

| 분석 | 결과 | 해석 |
|------|------|------|
| **인구통계** | 성비 균형(F 52%, M 48%), 60대 이상 고령층 밀집 | 다인종 합성 데이터 특성 |
| **입원 패턴** | LOS 평균 10.6일, 중앙값 10일 — 우측 편포 | 성별·연령별 LOS 차이 없음 |
| **LabTestCount ↔ LOS** | 상관계수 0.993 | 역인과 위험 → 피처 제외 근거 |
| **PCA** | PC1 설명력 7.0% | 지배적 구조 없음 — 특정 검사가 대표 축 아님 |
| **t-SNE** | 균일 분포, 군집 없음 | 평균 수치 기반으로 환자 분리 불가 |
| **K-Means** | K=2에서만 미약한 분리 | 임상적으로 의미 있는 자연 군집 없음 |

→ EDA가 직접적으로 **"단순 평균 기반 표현의 한계"를 실증** → 구조적 파생변수 필요성 확인

## 4. 모델링 결과

### 성능 비교

| 모델 | R² (Test) | MAE | CV R² (5-Fold) |
|------|-----------|-----|----------------|
| Linear Regression | 0.825 | 1.697일 | 0.712 ± 0.068 |
| Random Forest (Tuned) | 0.916 | 1.157일 | **0.890 ± 0.035** |
| **XGBoost** | **0.918** | **1.123일** | 0.872 ± 0.030 |

RF 최적 파라미터: `max_depth=10, min_samples_split=5, n_estimators=200`

> XGBoost가 Test R² 기준 최우수. CV R²는 RF가 근소하게 높아
> 소규모 데이터 특성상 두 모델은 실질적으로 동등하다고 해석.

## 5. SHAP 분석 — 임상 신호 실증

모델을 해석 도구로 활용하여 EDA 가설을 실증하였다.

```
피처 그룹별 LOS 예측 기여도 (XGBoost 기준)

이상 소견 누적  ████████████████████████████  70.1%
변동성          ████                           중간
검사 평균       ███                           10.1%  ← 하위
시간 추이       ██                             하위

```

- `Total_Abnormal_Count` SHAP 기여값: **4.203**
- 2위 `Lab_Std_CBC:EOSINOPHILS` SHAP 기여값: **0.133** (31배 차이)

### 가설 검증 결과

| 가설 | 결과 |
|------|------|
| 단순 평균은 충분하지 않다 | ✅ Lab_Mean 그룹 기여도 최하위(10.1%) |
| 이상 누적이 핵심 신호다 | ✅ Total_Abnormal_Count가 70.1% 독점 |
| 변동성이 불안정성을 반영한다 | ✅ Std/Variability 그룹 중간 이상 기여 |
| 시간 추이가 방향 정보를 제공한다 | ✅ Trend 그룹 의미 있는 기여 확인 |

### SHAP Dependence — 효과 형태 탐색

SHAP Dependence Plot에서 `Total_Abnormal_Count`의 효과는 일정 수준 이상에서 급증하는 **임계점 패턴**이 관찰되었다. 이는 단순 선형 관계가 아닌 비선형 구조가 존재함을 시사한다.

# Analysis Summary

> 노트북 실행 없이 분석 전체 흐름과 결론을 파악할 수 있는 요약 문서.

---

## 1. 분석 배경 및 가설

EMR 데이터에서 흔히 사용되는 검사 수치의 단순 평균(mean)은  
환자 상태의 시간적 변화나 전반적 불안정성을 포착하지 못한다는 한계가 있다.

**가설:** 비정상 소견의 누적 빈도와 검사 수치의 변동성이  
평균값보다 입원 기간(LOS)과 더 강한 연관성을 가질 것이다.

**분석 대상:** Synthea 합성 EMR 데이터 (100명 / 372건 입원 / 111,483건 검사)

---

## 2. 피처 엔지니어링

| 변수 | 설명 | 설계 의도 |
|------|------|-----------|
| `Lab_Mean` | 검사 수치 평균 | 기준 비교용 |
| `Lab_Std` | 검사 수치 표준편차 | 개별 변동성 |
| `Lab_Trend` | 입원 기간 내 선형 기울기 | 수치 악화/호전 방향 |
| `Abnormal_Sum` | 입원별 이상 소견 누적 | 검사 단위 중증도 |
| **`Total_Abnormal_Count`** | 환자 전체 이상 소견 합 | **핵심 → SHAP 1위** |
| `Total_Lab_Variability` | 환자 단위 전반 변동성 | 생리적 불안정성 |

`LabTestCount`(총 검사 횟수)는 LOS와 r=0.993이나 역인과 관계 의심으로 **제외**.  
제거 후에도 XGBoost R²=0.918 달성 → 순수 임상 신호만으로 예측 가능함을 확인.

---

## 3. EDA 주요 결과

| 분석 | 결과 | 해석 |
|------|------|------|
| PCA | PC1 설명력 7.0% | 지배적 구조 없음 — 특정 검사가 대표 축 아님 |
| t-SNE | 균일 분포, 군집 없음 | 평균 수치 기반으로 환자 분리 불가 |
| K-Means | K=2에서만 미약한 분리 | 임상적으로 의미 있는 자연 군집 없음 |

→ EDA가 직접적으로 **"단순 평균 기반 표현의 한계"를 실증** → 구조적 파생변수 필요성 확인

## 4. 모델링 결과

### 성능 비교

| 모델 | R² (Test) | MAE | CV R² (5-Fold) |
|------|-----------|-----|----------------|
| Linear Regression | 0.825 | 1.697일 | 0.712 ± 0.068 |
| Random Forest (Tuned) | 0.916 | 1.157일 | **0.890 ± 0.035** |
| **XGBoost** | **0.918** | **1.123일** | 0.872 ± 0.030 |

RF 최적 파라미터: `max_depth=10, min_samples_split=5, n_estimators=200`

> XGBoost가 Test R² 기준 최우수. CV R²는 RF가 근소하게 높아  
> 소규모 데이터 특성상 두 모델은 실질적으로 동등하다고 해석.

### SHAP 분석

```
피처 그룹별 LOS 예측 기여도 (XGBoost 기준)

이상 소견 누적  ████████████████████████████  70.1%
변동성          ████                           ~
시간 추이       ██                             ~
검사 평균       ██                           10.1%  ← 최하위
```

- `Total_Abnormal_Count` SHAP 기여값: **4.203**
- 2위 `Lab_Std_CBC:EOSINOPHILS` SHAP 기여값: **0.133** (31배 차이)

**가설 검증 결과:**

| 가설 | 결과 |
|------|------|
| 단순 평균은 충분하지 않다 | ✅ Lab_Mean 그룹 기여도 최하위(10.1%) |
| 이상 누적이 핵심 신호다 | ✅ Total_Abnormal_Count가 70.1% 독점 |
| 변동성이 불안정성을 반영한다 | ✅ Std/Variability 그룹 상위권 |

### 잔차 분석

- 잔차 평균: 0.077일 (무편향)
- 잔차 std: 1.500일
- 대오차 케이스: 19건 (Test 75건 중 25%) — 극단 LOS에서 집중
- → 진단 중증도 등 현재 피처가 포착하지 못하는 임상 요인 존재

## 1. 분석 배경 및 문제 정의

EMR 데이터에서 흔히 사용되는 검사 수치의 단순 평균(mean)은  
환자 상태의 시간적 변화나 전반적 불안정성을 포착하지 못한다는 한계가 있다.

**가설:** 비정상 소견의 누적 빈도와 검사 수치의 변동성이  
평균값보다 입원 기간(LOS)과 더 강한 연관성을 가질 것이다.

**분석 대상:** 공개 EMR 데이터 (100명 / 372건 입원 / 111,483건 검사)

---

## 2. 피처 엔지니어링 설계

| 변수 | 설명 | 설계 의도 |
|------|------|-----------|
| `Lab_Mean` | 입원 기간 중 검사 수치 평균 | 기준 비교용 |
| `Lab_Std` | 검사 수치 표준편차 | 개별 검사 내 변동성 |
| `Lab_Trend` | 입원 기간 내 선형 기울기 | 수치 악화/개선 방향 |
| `Abnormal_Sum` | 입원별 이상 소견 누적 | 임상적 중증도 프록시 |
| `Total_Abnormal_Count` | 환자 전체 이상 소견 합 | **핵심 지표 후보** |
| `Total_Lab_Variability` | 환자 단위 전반적 변동성 | **핵심 지표 후보** |
| `LabTestCount` | 총 검사 횟수 | 진료 강도 반영 |
| `HoursAfterAdmission` | 입원 후 검사 경과 시간 | Trend 계산 기반 |

## 3. EDA 주요 결과

### 3.1 차원 축소 (PCA / t-SNE)

- PCA: 개별 주성분 설명력이 전반적으로 낮음 → **특정 검사가 대표 축이 되지 않음**
- t-SNE: 환자 샘플이 고르게 분포, 국소 군집 없음
- **결론:** 평균 검사 수치 기반 표현만으로는 환자 임상 특성 분리가 어려움

### 3.2 군집화 (K-Means)

- Elbow / Silhouette 분석에서 K=2 외 명확한 군집 분리 없음
- **결론:** 평균 수치의 선형 결합으로는 임상적으로 의미 있는 자연 군집이 형성되지 않음

→ EDA 결과가 구조적 파생 변수(Trend / Variability / Abnormal Count)의 **필요성을 직접 입증**

- 5-Fold CV와 Test R²의 격차가 크지 않아 **과적합 없이 일반화**

### 4.2 SHAP 분석 — 예측 기여 변수

```
순위  변수                    기여도 방향
─────────────────────────────────────────────────────────
 1   Total_Abnormal_Count    ↑ 누적 많을수록 LOS 증가
 2   Total_Lab_Variability   ↑ 변동성 클수록 LOS 증가
 3   Lab_Std                 ↑ 개별 변동성 클수록 LOS 증가
...  인구통계 변수            (기여도 상대적으로 낮음)
```

**핵심 발견:** 단일 검사 수치보다 **이상 소견의 누적과 전반적 변동성**이 LOS 예측에 결정적

## 5. 임상적 해석

- 환자의 개별 검사 수치 하나가 아닌, 입원 기간 전반에 걸친 **비정상 신호의 패턴**이 중요
- 이는 현장에서 의사가 환자 상태를 평가할 때 단일 수치보다 **전반적 추세**를 보는 방식과 일치
- 모델 결과가 도메인 지식과 정렬됨 → **설명 가능한 예측 근거 확보**
